<Warning>
This page describes a legacy TCAP instruction family retained in source. The current TSN credit instruction does not initialize or update `TCapTinTipV1`. Do not use this page as a setup guide for the current credit flow.
</Warning>

TCAP source still contains `TCapTinTipV1` and older initialize, credit, debit, exit, and liability instructions. These instructions model a stable per-TIN tip account and are distinct from the current TSN credit path, which invokes `credit_gpru_memo_v1` and advances TCAP's shared commitment-root account.

The presence of a legacy instruction or SDK decoder is not evidence that TSN XP currently invokes it or that it represents the authoritative latest balance. Current public guidance is in [GPRU and TCAP state](/architecture/gpru-confidential-balances) and [Current technology](/about/current-technology).
