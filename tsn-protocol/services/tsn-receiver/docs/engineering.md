# Receiver component engineering

Read repository instructions, [architecture](architecture.md), [verification](verification.md), the affected family README and [inventory](../core/component_inventory.json). [Node guidance](../../tsn-node/AGENTS.md) establishes MCES; Receiver applies responsibility isolation through TypeScript rather than copying Python descriptor mechanics.

Each authored runtime function, constructor, method and callback occupies one file. Constants, models, dependency declarations, class shells and explicit facades may contain no implementation. Tests retain discovery registrations and place cases/fixtures in functional directories. Use named imports, documented package ownership and exactly compatible shared helpers; preserve distinct serialization contracts.

Compose environment, clock, transport, database and wakes at the original facade/route boundary. Stateful components receive narrow ports. Do not locate mutable state through a server namespace or execute generated source in production. Preserve HTTP methods/aliases, imports, arities, canonical bytes, encrypted formats, permissions, leases and atomic transactions.

Sort local work by authoritative TCAP accounting addresses with funding/TIN unassigned. Preserve canonical manifest ordering, safe paths and committed-journal recovery. A missing anchor is an empty new store; existing monolithic anchors must fail closed without conversion or backup creation. Tests use temporary explicit storage contexts and never touch operator state through module import or source verification.

Project already-read coordination rows through the shared Node projection rather than fetching each funding document again. Ordinary point reads load only the indexed row; ordinary queries load the requested collection before evaluating existing query rules. Recover the journal first, validate every manifest path and validate each selected record without caching. Mutation and initialization-compaction snapshots, together with journal preflight, retain global record validation and the sixteen-record concurrency bound. Preserve manifest ordering, and keep the `Promise.allSettled` batch barrier until every started operation settles before an error releases the exclusive lock.

Schedule every local acquisition through the shared path queue, preserve its combined ten-second waiting/acquisition budget, reject nested same-path operations before initialization and ensure expired queued callbacks never run later. Keep fresh reads, native token ownership and the journal transaction boundary. Stage the bounded stale-rate cleanup page in one batch; retain its filter and hundred-row limit. These repairs introduce no operator procedure, configuration setting or API.

Capture baseline behavior, then verify compilation, interfaces, component invariants and relevant transaction/HTTP differences. Finish with the complete available offline suite, updated inventories and affected documentation in both destinations. Report missing hosted/live checks separately; extraction does not authorize services, signing/submission, deployment or Git publication.

The November 18 staged-funding change is an explicit behavioral replacement. Initial authorization excludes signed-deposit fields; readiness has no execution projection or Cranker eligibility. Keep the immutable initial commitment, encrypt private preflight, preserve its accepted attestation/lease context, and create final settlement only with atomic signed attachment. Exact attachment retries cannot become a deposit replacement. The `claim_once` nonce operation permits only the same serialized work/initial-commitment binding; existing `consume_once` remains one-use.
