TrustLink Labs is building foundational infrastructure for the **Internet of Value** through **TSN (Transfer Settlement Network)**, a hybrid settlement network designed to make value transfer interoperable, identity-aware, and privacy-preserving across applications and blockchain networks. TSN combines off-chain coordination and verification with on-chain authorization and settlement enforcement. **TSNP (Transfer Settlement Network Protocol)** names the on-chain settlement protocol within the broader TSN infrastructure; cross-network routes are described as live only when supported by deployment evidence.

The protocol separates transfer identity, private-state verification, and asset governance. TIP manages transfer identities such as TIN; GPRU is designed to guard the private state presented to TCAP; TCAP governs accepted assets and applies authorized settlement. The native-credit proof hides the TIN route and predecessor witness from the on-chain statement, but its amount, asset, shared roots, nullifier, successor point and encrypted Memo remain public. The published nullifier is derived from public deposit data, so funding and credit can be linked. The Node resolves private routing and constructs the witness, so this boundary does not establish owner-only knowledge or immunity to timing and transaction correlation. Direct wallet transfers expose their endpoints; confidential debit and exit require separate execution evidence. See [the privacy limits](/security/threat-model) for the current encoding and trust assumptions.

TrustLink Labs also develops TSN XP as a reference application for interacting with the protocols and SDKs. This site focuses on protocol responsibilities and application integration; implementation discussions, service operations, and deployment records live in the [repository documentation](https://github.com/bigdreamsweb3/trustlink-pay/tree/main/docs).
