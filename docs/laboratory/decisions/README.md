# Architecture decision register

These ADRs reconstruct decisions from current implementation and explicit repository instructions. They are dated by documentation review, not invented original approval dates. Alternatives are identified as historical only where a source record exists; an analytical comparison is not evidence that the team evaluated it at the time.

- [ADR-001: authority and work ownership](ADR-001-authority-and-work.md).
- [ADR-002: shared root and proof-gated accounting](ADR-002-shared-root.md).
- [ADR-003: one proof-bound owner delta](ADR-003-delta-binding.md).
- [ADR-004: documentation authority and separation](ADR-004-documentation-authority.md).

For a new decision, record context, problem, alternatives with evidence, decision, rationale, consequences, status and implementation/test links. Mark a proposal PROPOSED until adopted; a source-backed reconstructed decision does not certify external governance approval or deployed readiness.
