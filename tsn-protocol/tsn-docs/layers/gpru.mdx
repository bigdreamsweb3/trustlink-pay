# GPRU: Guarded Privacy Routing Unit

GPRU is a standalone Solana program that verifies cryptographic relations used by TSN and TCAP. The current TSN credit instruction calls GPRU to verify DNA-key derivation and validate an encrypted credit transition. GPRU does not custody TCAP assets.

## Current credit verifier

TIP stores a versioned GPRU ElGamal scan public key and its commitment. TSN passes the TIP registry and transaction-specific DNA key proof to GPRU. For the credit transition, GPRU checks the first encrypted credit or verifies ElGamal addition against a predecessor ciphertext supplied with the request. It does not store a per-TIN latest head in this path.

The commitment and ciphertext checks establish the specified relation for the supplied values; without persistent authenticated per-TIN head state, they do not prove that the supplied predecessor is the latest state for the TIN.

## Hidden-head verifier source

GPRU also has a Groth16 proof verifier and a Circom source for proving a hidden route-and-asset head update, sequence advancement, Memo/action binding, and nullifier update. The public inputs include old/new TCAP roots, Memo/action commitments, a nullifier, and TIP's shared route root. TCAP has an instruction that invokes this verifier and advances its global commitment root.

This is a separate source path. The active TSN, Node, SDK, and Cranker settlement flow does not call it. The repository does not establish circuit compilation, proving-key artifacts, proof generation, initialized verifier state, or end-to-end chain execution. The circuit does not prove homomorphic balance arithmetic, affordability, or solvency. The current instruction ABI exposes action kind, token ID, and amount.

## Privacy boundary

The hidden-head proof is designed to conceal the selected route and per-route head. Every update still writes the same public TCAP root account, exposing a shared protocol-level link and ordering. The current wired credit path also passes a TIP registry account, and public wallet funding remains visible. GPRU does not make the system zero-linkable.
