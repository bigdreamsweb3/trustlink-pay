TrustLink Labs welcomes protocol engineers, cryptographers, security researchers, distributed-systems developers, technical writers, and open-source contributors.

## Start here

- [TrustLink Labs on GitHub](https://github.com/Trustlink-Labs)
- [TSN protocol repository](https://github.com/bigdreamsweb3/trustlink-pay)
- [Research library](https://github.com/Trustlink-Labs/Trustlink-Research)
- [Protocol blog](https://tsn-protocol.blogspot.com)
- [TrustLink Labs on X](https://x.com/TrustLinkLabs)

The TSN SDK is currently a private workspace package. Application-facing documentation here shows its intended use; access to source and package builds is managed through the repository.

For implementation issues, integration discussions, deployment, or service operations, use the repository's [root documentation](https://github.com/bigdreamsweb3/trustlink-pay/tree/main/docs). This Mintlify site focuses on protocol responsibilities and application SDK behavior.
