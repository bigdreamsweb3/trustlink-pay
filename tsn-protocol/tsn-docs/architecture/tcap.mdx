TCAP (Transfer Confidential Asset Protocol) governs approved assets, reserves, and liability accounting. The TSN credit ABI carries a hidden-head proof to TCAP, which calls GPRU before atomically advancing one shared commitment root and reserve liabilities.

## Current TIN credit state

The TSN instruction invokes TCAP `credit_gpru_memo_v1`. TCAP checks the canonical global root and next sequence, approved asset, authorization signer, validity window, pending liability, and reserve solvency, then invokes GPRU's hidden-head Groth16 verifier. A valid proof allows TCAP to update the shared root and liabilities atomically.

The root is protocol-wide replay sequencing, not a per-TIN account. The proof is intended to establish that the hidden predecessor head is current and to advance it. This path does not initialize or update `TCapTinTipV1`.

The encrypted balance record is carried in the transaction Memo and bound by commitment. TCAP does not persist Memo history in a per-TIN account. A wallet or application reads history through RPC or an indexer.

## Funding-derived transition commitment

TSN derives a transition nullifier from the signed reserve-funding transaction and binds it into the authorization digest passed to TCAP. TCAP includes that value in the global-root transition. It is not a separate spent-funding account, and the global root does not prove per-TIN ciphertext freshness.

## Proof setup and runtime status

The TSN/TCAP source ABI carries the Groth16 proof and TCAP invokes GPRU. The circuit source includes balance arithmetic constraints, but no compiled circuit, setup keys, validated key converter, prover/witness service, initialized verifier, or end-to-end proof evidence is present. Node settlement authorization currently fails closed. The ABI exposes action kind, token ID, amount and other public inputs; the common writable TCAP root remains visible in each transition.

## Legacy TIN-tip source

TCAP retains `TCapTinTipV1` and older initialize, credit, debit, exit, and liability instructions in source. Those instruction families are separate from the current TSN credit call; do not infer current XP account requirements from them.
