The TSN TypeScript SDK helps an application connect to configured TSN services, work with TIP identities, prepare wallet-authorized payment intents, and follow their status. The application supplies its service endpoints and wallet integration; the SDK does not start or manage TSN infrastructure.

The SDK is maintained as a private workspace package and is not currently available through the public npm registry. Workspace build and service-operation instructions belong in the [repository documentation](https://github.com/bigdreamsweb3/trustlink-pay/tree/main/docs). The pages here focus on application-facing functions and expected request behavior.

## Check configured network services

The application chooses the endpoints and passes them to the SDK. Keep environment-specific URLs in the application configuration rather than hard-coding them into shared package code.

```ts
import { getTsnNetworkStatus } from "@trustlink/tsn-sdk";

const status = await getTsnNetworkStatus({
  live: {
    node: process.env.TSN_NODE_URL,
    receiver: process.env.TSN_RECEIVER_URL,
    rpc: process.env.TSN_RPC_URL,
  },
});

if (!status.readyForNativeTransactions) {
  throw new Error("TSN is not ready for native transactions");
}
```

Network readiness only reports whether configured dependencies respond. It does not authorize a payment or confirm settlement.
