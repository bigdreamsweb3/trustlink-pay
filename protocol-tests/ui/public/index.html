Create your private TIN

You do not choose or type the TIN. Solana assigns it during the on-chain creation transaction, and the finished TIN is shown only after the Cranker finalizes the operation.

Phone ownership verificationNot verified. An OTP/attestation provider is required before issuance.

Random mode generates the secret in this browser and displays it to the creator. Phone mode is only a UI path until a real OTP or attestation provider is connected. Neither mode publishes the raw lookup value on Solana.
